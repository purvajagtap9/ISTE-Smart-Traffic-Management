# I-STE (Intelligent Smart Traffic Engineering)

Beginner-friendly starter project for a final year engineering major project.

## What this project includes

- Flask backend structure with Blueprints
- SQLite database setup through Flask-SQLAlchemy
- Login architecture placeholders (Google OAuth + Phone OTP)
- Modules for traffic detection, adaptive signals, enforcement, and documents
- Admin and user dashboards
- Public live traffic map page (Leaflet placeholder)
- Analytics page (Chart.js placeholder)

## Quick start

1. Create and activate virtual environment
2. Install requirements
3. Copy `.env.example` to `.env`
4. Run application

```bash
pip install -r requirements.txt
python run.py
```

## Notes for beginners

- Most Python files currently contain starter code and comments.
- You can implement one feature at a time.
- Keep testing small changes regularly.
